The directory /project/volvepub/Seismic/VSP contains checkshots for some wells.

The checkshots are normal incidence VSP. They are measured in the well. 
There is put a VSI tool in the borehole, with 4 receivers. The distance between 
the receivers is 15cm. A source is located right above the VSI receivers 
(in the center). The average TWT of first arrivals in the 4 receivers is taken. The boat and the VSI tool move after every shot.

More VSP data in folder Well logs\08.VSP_VELOCITY
